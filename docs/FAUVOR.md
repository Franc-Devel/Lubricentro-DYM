# FAUVOR Taller

## Rol dentro del catálogo

Gestión de taller e inventario.

Interfaz React y API Node.js para gestión de productos, caja, clientes, turnos y guía de vehículos. La demo de la landing utiliza datos locales y un adaptador de API estática.

## Identidad

El nombre visible del producto es **FAUVOR Taller**. Se conserva la URL `Franc-Devel/Lubricentro-DYM` para mantener los enlaces históricos. El símbolo y los iconos provienen del kit original FAUVOR. La paleta utiliza marfil, blanco cálido, bronce y dorado; los estados positivos usan un oliva sobrio.

Las portadas son ilustraciones conceptuales, no capturas de pantalla. No acreditan clientes, cifras de uso, resultados comerciales ni funciones que no estén implementadas.

## Ejecución

`npm ci`, `npm run build` y `npm run dev`. Consultá el README para la configuración del servidor y la base.

## Alcance y límites

La demo estática no sustituye al servidor y sus permisos. Su guía devuelve marcas/modelos como cadenas y fichas como objetos; las escrituras de la demo permanecen en memoria durante la sesión.

FAUVOR Flow es un proyecto independiente. No conecta automáticamente estas bases o servicios: cualquier integración futura debe implementarse y verificarse.
